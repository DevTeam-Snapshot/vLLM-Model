# Hotel Advertisement Image gRPC Server

FastAPI가 전달한 호텔 원본 이미지와 광고 문구로 OpenAI `gpt-image-2` 이미지 편집 API를 호출하고, 생성 PNG bytes를 돌려주는 내부 gRPC 모델 서버입니다. 파일 저장, URL 생성, PostgreSQL 기록 및 `pending → processing → completed/failed` 상태 관리는 FastAPI의 책임입니다.

## Contract

Proto source: [proto/hotel_ad_image.proto](proto/hotel_ad_image.proto)

| Item | Value |
| --- | --- |
| Docker service | `llm-service` |
| Internal address | `llm-service:50051` |
| Host test address | `127.0.0.1:15051` |
| RPC mode | Unary gRPC, no streaming |
| Model | `gpt-image-2` via `images.edit` |
| Supported input | JPEG, PNG, WebP; max 25 MiB |
| gRPC send/receive limit | 32 MiB on the model server |
| Output | PNG bytes with `image/png` |

### Request

```proto
message GenerateAdvertisementImageRequest {
  string request_id = 1;
  bytes hotel_image_bytes = 2;
  string image_mime_type = 3;
  string hotel_description = 4;
  string ad_copy = 5;
  string additional_instructions = 6;
}
```

`ad_copy` is a value entered by the hotel owner in React. It is not generated by a separate text model in v1.

### Response and errors

```proto
message GenerateAdvertisementImageResponse {
  bytes image_bytes = 1;
  string image_mime_type = 2; // image/png
}
```

| gRPC status | Meaning |
| --- | --- |
| `INVALID_ARGUMENT` | Missing fields or unsupported image MIME type |
| `RESOURCE_EXHAUSTED` | Source image exceeds 25 MiB, or a message exceeds the 32 MiB limit |
| `UNAVAILABLE` | OpenAI image-generation request failed |
| `INTERNAL` | Unexpected model-server error |

## Run

Create `.env` from `.env.example` and set an OpenAI Platform key.

```env
OPENAI_API_KEY=...
BACKEND_DOCKER_NETWORK=fastapi-backend_default
```

Start the server:

```bash
docker compose up --build
```

The model server does not use GPU, Hugging Face, a shared image folder, or image URLs.
It joins `BACKEND_DOCKER_NETWORK`, allowing the FastAPI container to resolve it as `llm-service:50051`.

## Backend stub generation

From the FastAPI repository, generate Python stubs from this repository's proto source.

```bash
python -m grpc_tools.protoc \
  -I ../vLLM-Model/proto \
  --python_out=. \
  --grpc_python_out=. \
  ../vLLM-Model/proto/hotel_ad_image.proto
```

Create the channel with the same 32 MiB limits:

```python
grpc.aio.insecure_channel(
    "llm-service:50051",
    options=(
        ("grpc.max_send_message_length", 32 * 1024 * 1024),
        ("grpc.max_receive_message_length", 32 * 1024 * 1024),
    ),
)
```

FastAPI must send the source image bytes and save returned PNG bytes into its own `Image/results` directory before recording the resulting image URL in PostgreSQL.

## Health Check

With `grpcurl` installed:

```bash
grpcurl -plaintext \
  -import-path proto \
  -proto proto/hotel_ad_image.proto \
  -d '{}' \
  localhost:15051 hotel.adimage.v1.HotelAdvertisementImageService/HealthCheck
```

Expected response:

```json
{"healthy": true}
```

OpenAI image-generation calls consume API credits. See the [official image generation guide](https://developers.openai.com/api/docs/guides/image-generation) for current API options.
