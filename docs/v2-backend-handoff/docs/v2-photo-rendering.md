# V2 호텔 광고 템플릿과 4:5 출력

V2 DraftImageService.GenerateDraft의 모든 후보·회차·모드는 **1080×1350 PNG, 4:5**를 반환합니다. 기존 원본 비율/정사각형/자동 비율 정책은 폐기했습니다. V1은 별도 레거시 경로입니다.

## 원본 기반 사진 처리

원본 bytes는 수정하지 않습니다. 제한적인 노출(0.96~1.06), 화이트밸런스(0.98~1.02), 대비·채도(1.02) 보정을 적용합니다. 수평은 긴 가로선이 충분히 감지된 경우에만 ±2도 범위에서 보수적으로 추정합니다. 회전으로 생기는 빈 모서리는 안쪽으로 자릅니다.

사진은 비율을 유지하며 4:5 캔버스를 채웁니다. 긴 방향의 넘치는 영역을 자르며 늘이기, 생성형 가장자리 채우기, 시설·전망 교체는 하지 않습니다. 가로 사진은 좌우가 많이 잘릴 수 있습니다. live의 OpenAI는 자르기 중심을 추천하지만 중요 시설 보존을 보장하지 않으므로 실제 사진 결과를 검수하세요.

## 세 가지 광고 디자인

| direction (기존 wire 값 유지) | 표시 이름 | 디자인 |
| --- | --- | --- |
| 1 / ROOM | 감성형 | 큰 확정 헤드라인, 강조 선, 장점 카드, 상세 보기 안내 |
| 2 / EMOTION | 장점 강조형 | 가장 중요한 장점의 큰 글자, 색상 패널, 보조 장점 |
| 3 / BENEFIT | 편집형 | 큰 제목, 장점 순번과 구분선, 상세 보기 안내 |

세 후보 모두 사진이 캔버스를 채우며 텍스트와 장식이 사진 안쪽에 겹칩니다. 디자인용 카드·패널은 사진 위 광고 그래픽이며 바깥 여백이 아닙니다. 장식은 코드로 그리므로 객실 사진을 생성형 모델로 재작성하지 않습니다. 폰트 굵기와 크기를 구분하고 긴 문구는 박스에 맞춰 축소합니다. 글자를 잘라내지 않으며 배치 불가 시 COMPOSITION_FAILED입니다.

2회차는 fake에서는 상하 배치·색상을 바꿉니다. live에서는 다른 적절한 구성을 요청하지만 서로 다른 결과를 보장하지 않습니다.

## OpenAI의 역할과 사실성

보정된 사진 미리보기, 확정 문구, 숙소명, 장점 목록, 분위기·색상 선호를 Responses API로 보냅니다. OpenAI는 자르기 중심, 제목 위치, 그라데이션 농도, 제한된 색상 팔레트와 강조할 장점의 순서를 선택합니다.

장점은 자유 생성 문구가 아니라 원본 목록의 인덱스 1~3개로 선택합니다. 중복·범위 밖 인덱스는 MODEL_OUTPUT_INVALID로 거절합니다. 선택한 장점 전체를 그대로 합성하므로 숫자뿐 아니라 '일부', '유료' 같은 조건도 유지됩니다. 숙소명과 확정 광고 문구도 그대로 사용합니다. 입력 사실의 진위 검증은 하지 않습니다.

할인·가격·조식·무료 제공을 임의로 추가하지 않습니다. '숙소 자세히 보기'는 이미지에 그린 안내이며 클릭 기능이나 예약 주소를 포함하지 않습니다.

Image Gen은 런타임에 호출하지 않습니다. 이번 구현은 검수된 코드 기반 장식과 템플릿으로 기본 품질을 확보합니다. 향후 검수된 Image Gen 장식 소재를 추가할 수 있지만 실제 호텔 사진을 교체하지 않습니다.

## 설정과 오류

V2 live에는 OPENAI_API_KEY가 필요합니다. 기본 분석 모델은 OPENAI_VISION_MODEL=gpt-4.1-mini, OPENAI_VISION_TIMEOUT_SECONDS=60, OPENAI_BASE_URL=https://api.openai.com/v1입니다. 기존 환경변수를 그대로 사용하며 추가 키는 없습니다.

후보별 OpenAI 호출은 1회, 세 후보는 3회입니다. 오류 시 자동 재시도나 fake 대체는 없습니다. fake는 외부 호출 없이 같은 4:5 템플릿을 사용하고 FAKE 표시를 넣습니다. HealthCheck는 폰트·키 설정을 검사하며 실제 인증은 live_check로 확인합니다.

## Backend·React 연동

- 기존 protobuf 필드 번호·enum 값·세 번의 호출 및 최종 선택 흐름은 유지합니다.
- 세 후보와 두 회차의 결과를 모두 1080×1350으로 저장하세요.
- 후보 라벨은 '감성형 / 장점 강조형 / 편집형'으로 바꾸세요. 원본 비율·정사각형·자동 추천 선택 UI는 제거해야 합니다.
- PNG를 다시 정사각형으로 자르지 마세요. 미리보기는 원본 4:5 비율을 유지합니다.
- 기존 캐시와 구분해 렌더러 버전을 올리거나 초안 캐시를 무효화하세요. 이 저장소는 Backend DB와 React를 소유하지 않습니다.
- 결과 PNG 메타데이터는 output_format=portrait_4_5, ad_template=emotional/spotlight/editorial입니다.

## 실행 검증

[SSH live 배포와 실제 API 테스트](v2-live-deployment.md)를 따르세요. v2.live_check는 세 결과 모두 1080×1350이고 OpenAI 경로인지 확인합니다. scripts/check_local.py는 자동 회귀 검사, scripts/smoke_local.py는 외부 API 없는 실제 gRPC 프로세스 검사입니다. 로컬 HTTP 응답을 사용한 SDK 검사만으로 실제 OpenAI의 구도 판단 품질이 검증되지는 않습니다.
