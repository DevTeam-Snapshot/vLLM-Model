05 / VALIDATION PLAN

약 $0.10의 1차 채팅 비교로 시작

  1. 한국어 테스트 30개를 고정

    정상 답변, 다중 필드 입력, 이전 값 정정, 삭제, 모호한 답변, 무관한 질문, 재확인 상황을 포함합니다.

  2. GPT-4.1 mini와 GPT-5.4 nano를 동일 조건으로 실행

    같은 스키마·문맥·입력을 사용합니다. 앞의 토큰 가정으로 30회씩 호출하면 약 $0.09675입니다. 실제 비용은 사용량으로 확인합니다.

  3. 필드 정확도·잘못된 완료 판단·지연을 비교

    명확한 정정 누락과 잘못된 완료 처리는 우선 수정합니다. 중요 실패 사례에 한해 GPT-5.4 mini를 추가 비교합니다.

  4. 동일 사진으로 A·B·C Medium 샘플 검증

    호텔 특징 보존, 광고 방향의 차이, 합성한 한글 문구의 정확성과 가독성을 확인하고 이미지 실제 단가를 보정합니다.

  5. 통과한 모델·설정을 고정해 통합 테스트

    정확도가 비슷하면 비용과 지연이 낮은 모델을 선택합니다. 프롬프트 버전과 생성 설정도 함께 기록합니다.
